# Godseye 👁️

Godseye is a Django-based trading application built to connect with broker APIs, manage trading accounts, process market data, and handle orders and positions.

## Features

- 🔌 Broker API integration
- 📡 Real-time market data using WebSockets
- 📊 Order and position management
- 💰 P&L tracking
- ⚡ Redis support
- 🗃️ Database support
- 📈 Market contract and instrument handling
- 🤖 Trading automation

## Tech Stack

- Python
- Django
- Redis
- PostgreSQL
- Pandas
- WebSockets
- Selenium
